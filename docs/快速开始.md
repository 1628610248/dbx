# 快速开始

## 环境要求

| 依赖 | 最低版本 | 说明 |
|------|----------|------|
| Node.js | >= 22.13 | 前端构建 |
| pnpm | >= 10.27 | 包管理 |
| Rust | >= 1.88 | Rust 编译 |
| Make | 任意版本 | 构建任务编排 |

### Linux 额外依赖

```bash
# Ubuntu/Debian
sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev \
  libappindicator3-dev librsvg2-dev patchelf libssl-dev
```

## 安装与运行

### 方式一：直接下载（推荐普通用户）

从 [GitHub Releases](https://github.com/t8y2/dbx/releases/latest) 下载对应平台的安装包。

```bash
# macOS (Homebrew)
brew install --cask dbx

# Windows (Scoop)
scoop bucket add dbx https://github.com/t8y2/scoop-bucket
scoop install dbx

# Windows (WinGet)
winget install t8y2.dbx

# Linux (Flatpak)
flatpak remote-add --if-not-exists flatpark https://dl.flatpark.org/flatpark.flatpakrepo
flatpak install flatpark com.dbxio.dbx
```

### 方式二：Docker 自托管

```bash
# 快速启动
docker run -d --pull=always --name dbx \
  -p 4224:4224 \
  -v dbx-data:/app/data \
  t8y2/dbx:latest

# 国内用户可使用 CNB 镜像
docker run -d --pull=always --name dbx \
  -p 4224:4224 \
  -v dbx-data:/app/data \
  docker.cnb.cool/dbxio.com/dbx:latest
```

浏览器打开 `http://localhost:4224`。

使用 Docker Compose：

```yaml
# deploy/docker-compose.release.yml
services:
  dbx:
    image: t8y2/dbx:latest
    pull_policy: always
    ports:
      - "4224:4224"
    volumes:
      - dbx-data:/app/data
    restart: unless-stopped

volumes:
  dbx-data:
```

```bash
docker compose -f deploy/docker-compose.release.yml up -d
```

### 方式三：从源码构建

```bash
# 1. 克隆仓库
git clone https://github.com/t8y2/dbx.git
cd dbx

# 2. 启动桌面端开发环境
make

# 3. 其他开发命令
make dev-fast          # 快速模式（跳过 DuckDB 编译）
make dev-web           # 仅启动 Web 前端
make dev-backend       # 仅启动 Web 后端
make build             # 类型检查 + 构建前端
make package           # 打包桌面应用
```

## MCP 服务器

让 AI 编程助手直接查询数据库：

```bash
# 通过 npm 安装
npx @dbx-app/mcp-server
```

在 `.mcp.json` 中配置：

```json
{
  "mcpServers": {
    "dbx": {
      "command": "npx",
      "args": ["-y", "@dbx-app/mcp-server"]
    }
  }
}
```

### 连接 DBX Web/Docker 后端

```json
{
  "mcpServers": {
    "dbx": {
      "command": "npx",
      "args": ["-y", "@dbx-app/mcp-server"],
      "env": {
        "DBX_WEB_URL": "http://localhost:4224",
        "DBX_WEB_PASSWORD": "your-web-login-password"
      }
    }
  }
}
```

### MCP 权限模式

在 **DBX 设置 → MCP** 中管理连接白名单和权限：

| 模式 | 机器可读值 | 说明 |
|------|-----------|------|
| 只读 | `read_only` | 仅允许 SELECT 查询 |
| 数据读写 | `safe_write` | 允许 INSERT/UPDATE/DELETE |
| 完全访问 | `high_risk_write` | 允许 DDL 等所有操作 |

## CLI 工具

```bash
# npm 安装
npm install -g @dbx-app/cli

# Homebrew 安装
brew tap t8y2/dbx && brew install dbx-cli

# 使用示例
dbx connections list --json
dbx query local "SELECT 1" --json
```

## 本地开发环境

```bash
# 安装依赖
make install

# 文档站
make docs              # 本地预览文档
make docs-build        # 构建文档站

# 代码检查
make check             # 运行项目检查
make test              # 运行测试
make cargo-check-fast  # 快速 Rust 检查
make cargo-test-fast   # 快速 Rust 测试

# 数据库测试环境
make db DB=mysql@8.4          # 启动 MySQL 8.4 测试环境
make db-verify DB=mysql@8.4   # 启动并运行冒烟测试
make db-down DB=mysql@8.4     # 停止环境
make db-list                  # 列出所有可用数据库版本
```
