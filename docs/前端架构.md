## 核心模块详解

### 数据网格 (Data Grid)

最复杂的前端模块，实现了类 IDE 的表格浏览器。

| 文件/目录 | 职责 |
|------|------|
| `lib/dataGrid/` (50+ 文件) | 纯逻辑：列宽、排序、过滤、分页、剪贴板、编辑适配器、SQL 生成、条件编辑器、单元格渲染等 |
| `composables/useDataGrid*.ts` (15+ 文件) | Vue 响应式桥接：运行时、编辑器、筛选器、导出、搜索、选择、列布局、自动刷新等 |
| `components/grid/` | 数据网格 UI 组件 |

### SQL 编辑器

基于 CodeMirror 6 深度定制。

| 文件/目录 | 职责 |
|------|------|
| `lib/editor/codemirrorSqlDialect.ts` | SQL 方言识别与切换 |
| `lib/editor/codemirrorSqlSemanticHighlight.ts` | 语义高亮（表名、列名、函数） |
| `lib/editor/sqlCompletionInsertion.ts` | 元数据感知的自动补全 |
| `lib/editor/keyboardShortcuts.ts` | 键盘快捷键注册（Cmd+Enter 执行等） |
| `lib/editor/editorThemes.ts` | 9 种编辑器主题 |
| `lib/editor/codemirrorStatementGutter.ts` | 语句行号装订线 |

### AI SQL 助手

| 文件/目录 | 职责 |
|------|------|
| `lib/ai/ai.ts` | AI 核心调度（多模型支持） |
| `lib/ai/aiMarkdown.ts` | AI 回复 Markdown 渲染 |
| `lib/ai/aiTableMentions.ts` | 表名提及与上下文注入 |
| `lib/ai/aiSqlAppend.ts` | AI 生成的 SQL 追加到编辑器 |
| `lib/ai/aiSqlExecutionPolicy.ts` | AI SQL 执行安全策略 |
| `lib/ai/aiReasoningPresentation.ts` | AI 推理过程展示 |
| `components/ai/` | AI 聊天面板 UI |

### 国际化 (i18n)

支持 8 种语言，所有 UI 文本通过 `vue-i18n` 管理。后端错误信息通过 `backend-errors.ts` 自动翻译为对应语言。

## 前端与 Tauri 通信

前端通过 `@tauri-apps/api` 与 Rust 后端通信：

```typescript
// 调用 Rust 命令
import { invoke } from "@tauri-apps/api/core";
const result = await invoke("execute_query", { connectionId, database, sql });

// 监听后端推送事件
import { listen } from "@tauri-apps/api/event";
listen("query-result", (event) => { /* 处理结果 */ });
```

对应的 Rust 端在 `src-tauri/src/commands/` 中定义了 50+ 个 `#[tauri::command]` 函数。

## 构建配置

Vite 配置 (`vite.config.ts`) 中关键优化：

- **代码分割**：CodeMirror、ECharts、Reka UI、Marked 分别独立 chunk
- **ECharts 精细拆分**：charts / components / renderers / core 四个独立包
- **Tauri 环境检测**：通过 `TAURI_DEV_HOST` 或 `TAURI_ENV_ARCH` 判断
- **基础路径**：支持 `VITE_DBX_BASE_PATH` / `DBX_PUBLIC_BASE_PATH` 反向代理部署
