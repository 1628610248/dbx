# 使用示例

## 桌面端

### 连接数据库

1. 打开 DBX 桌面应用
2. 点击左侧边栏 **"+"** 按钮
3. 选择数据库类型（如 MySQL、PostgreSQL、SQLite）
4. 填写连接信息（主机、端口、用户名、密码、数据库名）
5. 点击 **"测试连接"** 确认配置正确
6. 点击 **"保存"** 完成连接

### 执行 SQL 查询

1. 在左侧连接列表中选中数据库连接
2. 在编辑器区域输入 SQL：
   ```sql
   SELECT * FROM users WHERE created_at > '2026-01-01'
   ```
3. 按 `Cmd+Enter`（macOS）或 `Ctrl+Enter`（Windows/Linux）执行
4. 结果将显示在下方的数据网格中

### 使用 AI SQL 助手

1. 选中一个数据库连接和表
2. 按 `Cmd+I`（macOS）或 `Ctrl+I`（Windows/Linux）打开 AI 面板
3. 用自然语言描述查询需求：
   > "查询过去 30 天内注册的用户，按注册日期分组统计"
4. AI 将生成对应 SQL，你可以审查后执行

### 导入 CSV/Excel 数据

1. 右键点击目标表 → **"导入数据"**
2. 选择 CSV 或 Excel 文件
3. 映射文件列到表列
4. 预览导入数据，确认后执行

### 数据对比

1. 菜单栏 → **工具 → 数据对比**
2. 选择源连接和目标连接
3. 选择要对比的表
4. 查看差异结果，可选择同步数据

## Docker / Web 版

### 从 Docker 镜像启动

```bash
docker run -d --pull=always --name dbx \
  -p 4224:4224 \
  -v dbx-data:/app/data \
  t8y2/dbx:latest
```

浏览器打开 `http://localhost:4224`，使用 Web 界面进行数据库管理。

### 反向代理配置

将 DBX 部署在 `/dbx` 子路径下：

```yaml
environment:
  - DBX_PUBLIC_BASE_PATH=/dbx
```

Nginx 反向代理配置：

```nginx
location /dbx/ {
    proxy_pass http://localhost:4224/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

## CLI 工具

### 列出连接

```bash
dbx connections list
dbx connections list --json
```

### 执行查询

```bash
# 交互式查询
dbx query

# 命令行模式
dbx query my-mysql "SELECT 1"

# 输出 JSON 格式
dbx query my-mysql "SELECT * FROM users LIMIT 5" --json
```

### 导出数据

```bash
dbx export my-mysql "SELECT * FROM orders" --format csv > orders.csv
dbx export my-mysql "SELECT * FROM orders" --format json > orders.json
```

## MCP 集成示例

### Claude Code 集成

在项目的 `.mcp.json` 中配置：

```json
{
  "mcpServers": {
    "dbx": {
      "command": "npx",
      "args": ["-y", "@dbx-app/mcp-server"]
    }
  }
}
```

之后在 Claude Code 中可以：
- "列出我的所有数据库连接"
- "查看 users 表的结构"
- "查询最近 10 条订单"
- "帮我写一个查询，统计上个月的销售额"

### Cursor / Windsurf 集成

同样在 `.mcp.json` 中配置，AI 助手将自动获取数据库上下文来辅助编码。

### 远程 Web 后端集成

```json
{
  "mcpServers": {
    "dbx": {
      "command": "npx",
      "args": ["-y", "@dbx-app/mcp-server"],
      "env": {
        "DBX_WEB_URL": "https://dbx.example.com",
        "DBX_WEB_PASSWORD": "your-secure-password"
      }
    }
  }
}
```

## 开发构建

### 桌面应用打包

```bash
# macOS
make package

# Windows
cargo tauri build

# Linux
cargo tauri build
```

### 仅构建 Web 后端

```bash
cd crates/dbx-web
cargo build --release
```

### 构建 CLI

```bash
cd crates/dbx-cli
cargo build --release
```

### 构建 MCP 服务器

```bash
cd crates/dbx-mcp
cargo build --release
```

### JDBC Agent 驱动测试

```bash
cd agents
./gradlew test
```
